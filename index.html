2 Inspection card

Run a check to see results here. Fixed = corrected automatically. Review = look at it yourself. Error = must be resolved before import.

3 Formatted output

⚠ row(s) have an Allowance $ amount but UOM isn't "Allowance". Confirm whether Specification should read "Allowance".
⚠ row(s) flagged as section headings / separators. Nothing is deleted automatically - review, then remove if needed.
⚠ row(s) have a numeric UOM - a price likely landed in the UOM column.
⚠ row(s) had no Price_Each (no Unit Cost Ex. Tax in source) - defaulted to 0.00. Check and update these before importing.
